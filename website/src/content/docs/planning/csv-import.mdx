If your agenda already lives in a spreadsheet, don't retype it. **Agendas → Import CSV** creates a whole agenda — items, times, sub-item loops, and participants — from one paste.

## The short version

1. Make sure your sheet has a header row with a `title` column and at least one time column (`min`, `green`, `yellow`, `red`, or `max`).
2. Copy the cells and paste them into the **Agenda CSV** box (a paste from Excel or Google Sheets is tab-separated — that's fine).
3. Give the agenda a title and click import. Fix any per-line errors it points out, and paste again.

Optionally pick a [template](/planning/templates/) from the **Start from a template** dropdown first — it fills the box with the template's CSV, which you can still edit before importing.

## Format rules

- The **first row is a header**. Column names are matched ignoring case, spaces, underscores, and dashes, in **any order**: `title`, `min`, `green`, `yellow`, `red`, `max`, `person`, `sub label`, `sub min`, `sub green`, `sub yellow`, `sub red`, `sub max`, `url`. Unknown columns are ignored (so extra spreadsheet columns don't hurt).
- **`title` is required**, and every row needs **at least one time**. Files from before the five-time change (`min`, `expected`, `max`) still import — see [CSV columns](/reference/csv-columns/).
- The delimiter is auto-detected per paste: **tab, semicolon, or comma** all work.
- Quoted fields work as usual (`"a, b"` keeps its comma; `""` inside quotes is a literal quote). Blank lines are skipped.
- Times are **minutes** from 0.5 to 600 in **half-minute steps** — `10` or `10.5`, not `10.25`.
- A name in **`person`** creates that participant on the new agenda and assigns the row's item to them. The same name on several rows becomes one person.
- Filling any `sub` time (optionally with `sub label`) gives the item a [sub-item loop](/concepts/sub-item-loops/).

<Aside type="note" title="All-or-nothing">
Nothing is imported unless **every** row is valid. Errors are reported per line and field — e.g. `Line 4: sub yellow — Set a time for the sub-item` — so you can fix the sheet and paste again without ending up with half an agenda.
</Aside>

<Aside type="caution">
Import covers items, people, and item URLs (the optional `url` column, which becomes the item's QR code). The agenda description, scheduled start, and timezone are not part of the CSV format — set those after importing.
</Aside>

## Worked example

The first rows of the built-in Toastmasters template:

```csv
title,min,green,yellow,red,max,person,sub label,sub min,sub green,sub yellow,sub red,sub max
Opening and welcoming guests,2,2,3,4.5,5,President,,,,,,
Introduction by the Toastmaster of the Evening,2,2,3,3.5,4,Toastmaster,,,,,,
Helpers introductions: timer / grammarian / ah-counter,3,3,4,4.5,5,,Helper,1,1,1.5,1.5,2
Word of the day,1,1,2,2.5,3,Grammarian,,,,,,
Prepared speeches,2,2,3,3.5,4,Toastmaster,Speaker,5,5,6,6.5,7
```

Importing this creates five items; "President", "Toastmaster", and "Grammarian" appear on the participant roster and are assigned to their items; "Helpers introductions" and "Prepared speeches" get sub-item loops (Helpers at 1/1.5/2 minutes each, Speakers at 5/6/7).

The [full 12-item version](/reference/csv-columns/#the-toastmasters-template) is in the CSV reference — and ships as a ready-made template when the sample data is seeded.

## Round-tripping

[**Export CSV**](/planning/agenda-editor/#export-csv) on any agenda produces exactly this format, so export → edit in a spreadsheet → import is a natural workflow for recurring meetings.
